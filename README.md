# chatbot-vendas-desafio
O objetivo é desenvolver um Chatbot de Vendas com IA para Atendimento em Loja, projetado para apoiar profissionais comerciais em interações reais com clientes. A solução utiliza IA para estruturar pitchs, responder objeções, organizar informações sobre produtos e orientar follow-ups, aumentando a produtividade e a assertividade no atendimento.
